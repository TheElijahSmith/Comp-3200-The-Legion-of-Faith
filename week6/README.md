# Outbound

## Overview

This week we are focusing on proving our conceptual understanding of neural networks via diagram visualization.
We take our last week model and rebuild it in the cleaner diagram workflow, create our own diagrams from
descriptions of situations, and finally code our own model from a new diagram. We also run unit tests to prove
our code and comment on the value of this skill.
