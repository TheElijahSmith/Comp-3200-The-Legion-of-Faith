Part 3
1. The thermostat analogy
The knob - The knob represents the model's weight of parameter. Changing it changes how strongly an input affects the model's prediction
The prediction - The prediction is what the model produces after using its current knob settings and the input
The error - The error is the difference between what the model predicted and what the correct answer actually was
The learning step - The learning step changes the knob positions based on the error so that the model should make a better prediction the next time it sees similar data

2. Single neuron arithmetic
Weight doubled to 0.2 - Doubling the weight doubles the effect that the input has on the prediction
Weight set to 0 - This would mean that the neuron is ignoring the input because there is no weight that could give influence
Weight Negative -0.1 - A negative weight would mean that the prediction is going to be pushed in the opposite direction
If the answer should have been 1.7 - I would say it is too low and to get it to the answer it would need a strong positive contribution, which would mean increasing the weight

3. The big picture
   It is hard to find the right knob position cause there can be thousands of other weights interacting with one another so moving just one a tiny bit can move everything off.
   So that means that there isn't a simple calculation that can give us the perfect setting in a instant
