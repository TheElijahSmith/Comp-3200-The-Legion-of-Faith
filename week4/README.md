
# Multi-in Multi-out Model

## Description

This folder showcases the steps of creating a simple multi input, multi output machine learning model.
This is the same as a simple one layer (no hidden layer) neural network. This week by implementing
outer products our model learns to predict and manipulate 2 dimensional matrices of weights. We also
experiment with scaling the datasets in order to give the weights equal footing in terms of importance and freeze some of the weights to see how that effects training and weight compensation. Lastly we visualized
how the weights changed over time and proved our code through some simple test functions.
